Privacidade e armazenamento

Com a configuração do Supabase concluída, os dados são sincronizados na conta familiar. O armazenamento local serve apenas como cópia temporária; faça backups JSON regulares.

Para uso real com sincronização: publique o site com login individual e banco de dados protegido por regras de acesso. Nunca guarde senhas bancárias ou dados completos de cartões aqui.
